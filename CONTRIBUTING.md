# Участие в проекте

1. Создайте задачу или выберите существующую.
2. Создайте ветку от актуальной `main` под конкретное изменение.
3. Для технических утверждений укажите источник, точную модель и метод проверки.
4. Откройте pull request: опишите изменение, проверки и ограничения.

Отделяйте предположения от проверенных фактов. Не заявляйте совместимость по одному лишь похожему названию устройства или процессора.

Для изменений прошивки указывайте исходную сборку, версии инструментов и необходимые зависимости. Результат компиляции и результат проверки на устройстве описывайте отдельно.

Перед публикацией удаляйте личные данные из логов и снимков экрана. Не добавляйте дампы пользовательских разделов, секреты, закрытые ключи и сторонние файлы без прав на распространение.

Лицензия проекта пока не выбрана; добавление лицензии требует отдельного решения владельца. Сторонний код должен сохранять собственные уведомления и условия.
